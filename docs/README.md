# Fabric guides

These guides describe the code in this repository. Command help is available
through `fabric <command> -h`; most flags precede positional arguments.

- [Getting started](getting-started.md): two devices and key-less admission.
- [Messaging](messaging.md): queues, scoped workers and request/reply.
- [Architecture](architecture.md): identity, ownership, routing and guarantees.
- [Operations](operations.md): lighthouses, services, renewal and troubleshooting.
- [Vault](../vault/README.md): data placement, folder sync and mounts.

The [root README](../README.md) is the project entry point. The
[Python SDK](https://github.com/ioa-rocks/fabric-py) is a separate repository.
